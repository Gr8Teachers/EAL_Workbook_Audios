# EAL Workbook Audios

Audio and interactive activities for student unit workbooks, playable without a login.

Structure: `COURSE/UNIT/index.html` is the one-page teaching screen (activity list + activity panel).
Each activity is in `COURSE/UNIT/activities/`, audio in `COURSE/UNIT/audio/`, workbook images in `COURSE/UNIT/img/`.
Shared styles and scripts for the workbook-based activities are in `assets/`.
